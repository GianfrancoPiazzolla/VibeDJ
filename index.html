How to use

Loading tracks

Press LOAD TRACK on a deck or drag an audio file from your computer onto the deck. You can also drag files anywhere in the window: drop two and they land on decks A and B. Everything runs locally — nothing is uploaded to the internet.

Features

  • Overlaid waveforms in a single strip with a shared time axis and zoom: deck A on top, deck B on the bottom, so the two tracks can really be compared
  • Beatgrid visible on both halves: the grid of the deck you are listening to is solid, the other deck's is dashed; the marked bar is the downbeat (every 4 bars)
  • Each half shows the phase offset in ms against the beat: move the TEMPO fader until both grids stay aligned
  • Automatic BPM detection, beat loops (1/4, 1/2, 1, 2, 4, 8), 8 hot cues per deck (Shift+click to clear) — changing the length of a loop that already exists keeps its IN point and only moves the OUT: the loop expands or contracts around its own start instead of jumping to the current position
  • Quantize (switch next to the PHONES knob in the mixer): snaps cue points, hot cues, loops and beat jumps to the nearest beat when a beatgrid is available
  • Interface zoom: the − / + buttons in the centre of the top bar resize the whole interface from 30% to 120% (CSS zoom: every element scales uniformly, waveform strip included, so nothing is cut off; when zoomed out the decks and mixer shrink while the waveform strip stretches vertically to fill all the remaining page space, leaving no empty gap at the bottom — modals, toasts and tooltips zoom too, and the setting is remembered)
  • Beat jump: −16 / −8 / −4 / +4 / +8 / +16 beats per deck
  • BPM/grid tools per deck: ×2 and ÷2 rescale the beatgrid, the arrows nudge it, SET lets you type a BPM manually and TAP sets it by tapping the beat
  • Per-deck Effects: delay, echo, flanger, reverb, phaser and bitcrush — toggle each one with the buttons in the FX row of the deck
  • Per-deck Stems: vocal, instrumental, bass and drums — every part plays by default and each button in the STEMS row mutes / unmutes its part, like rekordbox (a Linkwitz-Riley band split with dynamic centre and transient masks, not AI source separation)
  • Pioneer DDJ-FLX4 (button in the top bar): connect the controller over USB for full bidirectional MIDI control — transport, jog, tempo, loops, hot cues, pads (effects, beat jump, stems, beat loops), trim, EQ, filter, faders, crossfader, effects, quantize, library and LEDs. The master + PFL mix can be routed to the controller's USB audio output (Chrome/Edge) and the mapping is editable in the FLX4 dialog
  • Library (button in the top bar, shortcut F3): opens a modal where you can pick a local folder and list its audio files. Each row shows the estimated BPM, the harmonic key (Camelot, e.g. 1A) and an Energy tag (1-5); tracks already loaded onto a deck are highlighted in amber. Double-click = load the first free deck, A / B buttons = load a chosen deck, or drag a row onto a deck (the list shows only the playable audio files sitting directly in the selected folder — subfolders are not listed — and REFRESH re-reads them). With a DDJ-FLX4 connected you can scroll the selection with the BROWSE rotary, load it with the LOAD ◁ / ▷ buttons and open or close the Library by pressing the rotary
  • Custom key map: the keyboard layout is a JSON map you can edit right here (section Custom key map below) — remap any key, press APPLY and it is stored in this browser and reloaded on every start. A key can only drive one action, so APPLY refuses a map with conflicts and tells you which ones clash
  • SYNC: automatically aligns the other deck's tempo and phase
  • 3-band EQ with kill, LP/HP filters, trim, channel faders and a constant-power crossfader
  • Jog wheel: drag to scratch (while playing) or scrub (while paused)
  • Headphone monitoring (PFL) and mix recording

Keyboard shortcuts

Deck A uses the left half of the keyboard and deck B mirrors it on the right. Every control shows its key in the tooltip (hover it). Select an analog control with its key, then use the up/down arrows to adjust it.

Custom key map

Remap the keyboard by editing this JSON and pressing APPLY. It has the same shape as the built-in map (groups deckA, deckB, mixer, global); omit anything you want to keep at the default, or use RESET to restore the whole built-in map. A key cannot be assigned to two actions at once (case matters: z and Z are different keys), and ??? means unassigned. The map is stored in this browser and loaded on every start.

Notes

The TEMPO fader also changes the pitch of the track (there is no key lock) and is oriented like the hardware: sliding it up slows the track down, sliding it down speeds it up. Above each jog you can read the total track time, the time left, the current BPM and the harmonic key in Camelot notation (for example 1A). On the overlaid waveform strip the wheel or the +/− buttons zoom both decks together (shared time axis); clicking seeks the deck of the half you clicked (A on top, B on the bottom). Works best in Chrome/Edge. The recording is saved as a file when recording stops.

Synopsis: VibeDJ is a webapp for DJing right in the browser. Load two tracks, let it detect BPM and beatgrids, then sync and mix them with EQ, filters and per-deck effects (delay, echo, flanger, reverb, phaser, bitcrush), mute/unmute stems (vocal, instrumental, bass, drums), set loops and hot cues, and record your set. Everything runs locally — nothing is uploaded.

Pioneer DDJ-FLX4

Not connected. Press DDJ-FLX4 in the top bar to enable the controller.

The master + PFL mix is routed to the controller's USB audio interface. A browser can only send one stereo stream to one output, so the headphone jack carries the same mix (use HEADPHONE MIX / LEVEL to blend PFL).

MIDI mapping

A single editable JSON object. All numbers are decimal MIDI values and channels are 0-based (0 = MIDI channel 1). Changes are stored in this browser; RESET restores the built-in map. Close rekordbox before connecting so the controller exposes its MIDI surface.

Mapped controls

Transport PLAY / CUE / SYNC, jog (outer = pitch bend, touched platter = scratch, otherwise bend, SHIFT = fast seek), TEMPO fader, loops (IN / OUT / 4 BEAT / CUE LOOP CALL), pads (HOT CUE sets/jumps, SHIFT clears; PAD FX toggles effects; BEAT JUMP and BEAT LOOP; SAMPLER pads 1-4 = the four stems in the same left-to-right order as the on-screen STEMS row (VOCAL, INST, BASS, DRUMS), 5-8 = effects), TRIM, EQ, CFX = filter, channel fader, CH CUE, CROSSFADER, MASTER, MASTER CUE, headphone mix/level (both blend the PFL bus), FX CH1/CH2 (target deck) / SELECT / ON / LEVEL, BEAT ◁ / ▷ = beat jump, SMART CFX = quantize, SMART FADER = unmute all stems, BROWSE rotary = scroll the Library selection (highlighted only while the controller is connected), LOAD ◁ / ▷ = load the selected track onto deck A / B, BROWSE press = open or close the Library.
